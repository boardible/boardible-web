# Boardible Web

Marketing website redesign for Boardible, built in Next.js and intended for deployment on Vercel.

## Stack

- Next.js App Router
- TypeScript
- CSS-first styling with a custom visual system

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Create a new GitHub repository under the Boardible account.
2. Push this folder as its own repository.
3. Import the repository in Vercel.
4. Set the production domain in Vercel.
5. Point the Squarespace-managed DNS to Vercel using the records Vercel provides.

## Suggested repository name

- `boardible-web`
- `boardible-site`
